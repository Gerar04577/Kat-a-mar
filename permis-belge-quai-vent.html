Où amarrer pour passer une nuit tranquille ?

On regarde le bateau d'en haut. Le quai est la bande grise. Les flèches bleues montrent le vent.

✗ Nuit agitée

Le vent souffle vers le quai. Il pousse le bateau contre le quai : ça cogne toute la nuit.

✓ Nuit calme

Le vent vient du quai. Il écarte le bateau du quai ; les amarres le retiennent. Le bateau reste calme.

Le mot du QCM : « sous le vent »

Sous le vent = l'endroit vers lequel le vent souffle. Au vent = l'endroit d'où il vient.

C'est pour ça que vous avez été piégé. Dans la mauvaise situation, le quai est sous le vent, mais votre bateau est au vent du quai. Vous avez pensé au bateau (« au vent ») ; le site pense au quai (« sous le vent »). Les deux décrivent la même mauvaise situation : la question est mal posée.

À l'examen, répondez « Sous le vent ». Truc : on parle toujours de l'endroit où l'on s'amarre. Un quai (ou une côte) sous le vent est celui sur lequel le vent vous pousse : à éviter.
